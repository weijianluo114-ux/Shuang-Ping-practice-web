# 双拼练习 · 本地版

一个纯本地、无登录、无广告的双拼练习小网站（仿 shuangpin.xyz 的核心功能，为自己使用而做）。

## 怎么用

直接**双击 `index.html`** 用浏览器打开即可，完全离线可用，不需要任何服务器。

建议把它设为浏览器书签，每天练 10 分钟。

## 版本与发布流程（正式版 / 本地测试版）

采用**单仓库双分支**：

| 分支 | 用途 | 发布 |
| --- | --- | --- |
| `main` | 正式发行版 | GitHub Pages 自动发布 `https://weijianluo114-ux.github.io/Shuang-Ping-practice-web/` |
| `dev`  | 本地测试版 | 不发布，只在本地 `file://` 打开测试 |

版本号写在 `version.js`：`channel = "release"` 为正式版，`channel = "dev"` 为测试版；
页面顶栏会显示「v版本号」（正式版）或「测试版 v版本号」（测试版）。

日常开发流程：

1. 在 `dev` 分支上改代码，本地双击 `index.html` 测试；
2. 用 `node --check app.js` 和 `node --check article.js` 做语法检查（无头 Chrome 冒烟测试可选）；
3. 测试通过后：`git checkout main && git merge dev`；
4. 把 `version.js` 的 `channel` 改回 `"release"`（合并后只改这一行），并顺手 bump 版本号；
5. `git push origin main`，GitHub Pages 约 1 分钟后更新；
6. 每次正式发布打 tag：`git tag vX.Y.Z && git push origin vX.Y.Z`。

数据天然隔离：本地测试是 `file://`，正式版是 `https://...github.io`，两者 localStorage 互不相通。

## 功能

- **键位图**：小鹤双拼 / 自然码 / 智能ABC / 微软双拼 四套方案的完整键位图，
  敲实体键盘会高亮对应键帽，点键帽可查看该键的声母韵母，附各方案零声母规则说明。
- **键位记忆**：声母 / 韵母 / 零声母 三种速记训练，实时提示对错。
- **综合练习**：
  - 音节：随机音节流（可选 20 / 30 / 50 个一轮）
  - 词语：常用词打码练习
  - 句子：内置逐字注音的短句
  - 自定义：粘贴任意空格分隔的拼音串来练
  - 实时统计：用时 / 速度（字每分）/ 准确率 / 连击，完成后显示错键分布
- **文章练习**：整段中文照打——屏幕上显示汉字，逐字敲对应双拼编码。
  内置经典散文节选（朱自清、老舍、鲁迅、徐志摩）、随手短文，以及「联网获取十句」
  （一言 hitokoto.cn，联网失败时自动回退到内置句库）；也可粘贴任意中文段落开始练习。
  拼音提示可开关，段落自动分成一行行打，支持退格回退上一字。
  也可**导入本地文件练习**：支持 `.txt`（自动识别 UTF-8 / GBK / UTF-16）、
  `.md`（自动忽略标题、列表、链接、加粗等 Markdown 符号）和 `.docx`（提取正文文字），
  只读取文字内容，文件在本地解析、不会上传。
- **好词好句**：文章列表里的独立板块，联网抓取一言 hitokoto 优美句子无限续练——每批 10 句，
  打完自动再取 10 句直到退出；退出保存到具体某个字，下次进入继续；统计累计练习句数、
  累计时长（时/分）、坚持天数。
- **我的统计**：累计字数、准确率、时长、最近 7 天记录、累计错键分布（帮你定位弱键）。

所有数据只存在浏览器 `localStorage` 里，不联网、不上传。设置里可关提示 / 关音效 /
切深色主题 / 清除记录。

## 练习小贴士

1. 先把输入法切换成与网站一致的方案（网站右上角可切换）。
2. 练习时保持**英文输入状态**，按音节敲两键：`声母键 + 韵母键`。
3. 前期追求准确而不是速度；错了不要慌，看提示键位、慢速敲对即可。
4. 练完看「我的统计 → 错键分布」，把最常错的键放进「键位记忆」里加练。

## 方案数据准确性

四套方案的声母 / 韵母键位与零声母规则（小鹤、自然码为全拼式零声母，智能ABC、微软为 o 前缀式）
均对照公开的方案定义整理，编码转换逻辑经脚本逐例验证（含 ü、jqx 拼写、分号键 ing 等特例）。
汉字转拼音由 pinyin-pro 库负责（带词库的多音字消歧，如「重庆→chong/qing」「银行→yin/hang」），
内置文章共 1275 个汉字逐字验证全部可打。
